AI 進場之前，先問六件事

這些不是裝飾性的價值宣言，而是會出現在每份流程成果裡的治理檢查。

01

留意

最靠近問題的人看見了什麼？誰還沒被聽見？

02

負責

誰真的有權決定？失敗時由誰回答？

03

勝任

工具、資料與主持方法如何被測試與稽核？

04

回應

參與者如何更正、反對、申訴並要求修復？

05

團結

流程是否鼓勵跨差異合作，而不是平台綁定？

06

共生

AI 與工具是否有邊界、能關閉、會到期？

Optional AI collaboration

需要 Agent 時，有兩種入口

不想貼 API key，完全沒關係；skill 路徑可以在自己的環境執行。

方式一 · 單次 API

讓 AI 把拼圖整理成主持簡報

推薦結果仍由公開規則決定。AI 只負責把已選流程整理成節奏、人工關卡與風險提醒。

按下送出後，key 會經本站 Worker 傳到 OpenAI；本站不保存、不記錄。關閉分頁即清除。 


            


            

              方式二 · 啟動 skill
              
讓自己的 Agent 學會審議拼圖

              
Skill 會先問服務對象、風險、真正權限、申訴與關閉方式，再帶你來這裡產生可交接的配方。

              

                npx --yes github:mashbean/delib install-skill
                
              

              

                下載 SKILL.md
                
              

              

                這個 Agent 必須：
                
    
                  
  • 以 bounded local steward 身分協作，不自稱中立決策者；
    • 
                  
  • 忠實保存來源、歧見、撤回與不知道；
    • 
                  
  • 在範圍變大、要發布或要傳敏感資料前重新取得同意；
    • 
                  
  • 讓人能讀、改、申訴、停用並刪除記憶。
