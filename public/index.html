在 Delib 開啟 Pol.is

已有對話就貼網址；要自動建立新對話，第一次需要 Pol.is 帳號裡的 Site ID。

你現在是哪一種？

Site ID 是 Pol.is 帳號自動產生的公開識別碼，不是密碼。若部署時已連接，這裡可以留白。

登入 Pol.is 取得 Site ID ↗
按下開啟後會發生：
  • Pol.is 參與畫面會嵌入 Delib；
  • Delib 不複製或保存投票與陳述；
  • 資料保存、管理與刪除仍由 Pol.is 負責。

✓

工作區準備好了

留在 Delib 開啟 ↗

Pol.is 完整自架需要多個 Docker 服務與 PostgreSQL；Cloudflare Containers 只有付費方案，也不會供應 PostgreSQL。本站的一鍵部署會連接既有 Site ID，而不是假裝重寫整套 Pol.is。

在 Delib 填寫 HeyForm

貼上已發布的 HeyForm 公開網址，參與者就能留在這個工作區填寫；回答不會經過 Delib。

只接受公開參與網址，不接受後台網址、cookie、帳號或密碼。

開啟後會發生：
  • 已發布表單會嵌入 Delib；
  • 只有按下 HeyForm 的送出按鈕才會寫入回答；
  • 保存、匯出與刪除仍由表單主辦者負責。

✓

表單工作區準備好了

留在 Delib 開啟 ↗
還沒有表單？到 HeyForm 建立 ↗ 查看官方自架方式 ↗

HeyForm 自架需要 MongoDB 與 Redis／KeyDB，不是 Cloudflare-native。官方目前另有未修補的表單建構器安全公告；本站不代收登入憑證，也不自動代建表單。

現在可用 · 官方建立流程

用 Talk to the City 整理意見

先在 Delib 說清楚分析名稱與資料邊界，再於站內開啟 TTTC 官方頁登入、上傳 CSV、檢查並建立報告。

名稱與說明會出現在 TTTC 工作區網址；不要填入姓名、聯絡方式或敏感情境。

開啟後會發生：
  • Delib 只把名稱與說明帶入 TTTC 官方建立頁；
  • 登入 token 與 CSV 不會交給 Delib；
  • 按下 TTTC 的建立按鈕前，仍可返回或關閉。

✓

分析工作區準備好了

登入與資料上傳只發生在 Talk to the City。

留在 Delib 開啟 ↗

TTTC 現行版本使用 Firebase、Google Cloud Storage、Redis、Pub/Sub 與模型服務；舊 MetaGov adaptor 的 API 網域已不是現行公開入口，因此這版採官方 UI 連接，不要求使用者擷取 Firebase token。
