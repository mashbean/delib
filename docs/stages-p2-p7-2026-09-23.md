# 從分析走向主持 / From analysis to facilitation

2026-09-23. This delivery extends P2–P7 in sequence. Local baseline features are distinct from complete upstream reimplementations, authenticated decisions and partner acceptance.

## 可以立即操作 / Use now

1. [分析交接 / Analysis handoff](https://delib.mashbean.net/analysis?lang=zh) ([English](https://delib.mashbean.net/analysis?lang=en))：選校門虛構分群或三組公開選集 → 檢查來源、群組與缺值 → 下載 exchange → 工作台「帶回結果」。也可提供自己的同一狀態 statements.csv、results.json 與已有 synthesis.json。
2. [主持工作室 / Facilitation studio](https://delib.mashbean.net/facilitate?lang=zh) ([English](https://delib.mashbean.net/facilitate?lang=en))：建立虛構演練或選取本機議題 → 更正／場次／提案 → 保存 → 下載完整私人備份。和工作台共用 IndexedDB，沒有新增伺服器或付費 AI 呼叫。
3. [資料交換 / Handoff](https://delib.mashbean.net/handoff?lang=zh)：新增 Polis analysis、Metadecidim、Hypha 格式與虛構範例；先預覽欄位與損失，再匯入。

Analysis: choose a synthetic group-analysis example or a public excerpt set, inspect sources and missingness, download exchange, then use **Bring back results** in the workspace. Own files must describe the same activity/state. Existing synthesis is optional; no generation request is made.

Facilitation: create a fictional rehearsal or select a local issue, then record corrections, sessions and proposal progression. The studio shares the workspace's local storage and full private backup. No extra server or paid AI call is required. This is a facilitator's record, not multi-user conferencing or an authenticated voting service.

## P2：Polis

- 參考程式固定為 `mashbean/pocket-polis@f7ec343b6ec7ee39a7586f4eba49771f0009738c`。此版本是 adapter 的程式依據，不冒充正式服務回報的版本。
- 保留全體與群內票數、群組大小、遮蔽狀態、代表陳述、橋接分數、覆蓋率與納入分群比例；排除個人座標與跨人識別。
- 種子陳述、作者類型未知及分析不進入「參與者原話」交接。模型整理附多來源 ID；引用 ID 不等於逐字引文核實。
- 正式站唯讀核對紀錄：[evidence](../public/data/polis-analysis-evidence.json)。未呼叫會啟動生成的 `/synthesis`；沒有新增活動或投票。
- 綜整 `mathRevision` 是修訂號，**不是** `computedAt`。目前 results API 未提供相同修訂號，只能核對計數與引用，不宣稱同版。未提供 sourceRevision 保持 null。
- 綜整被投影成帶來源的段落；未保留各敘事區塊全部專用欄位，請保留原生 synthesis 檔。這不是逐位元備份。
- 三組公開選集固定於 compdemocracy/openData `3be5785c3f5975d31f4578ee8bbf4426d45b7bf2`：vTaiwan UberX、西雅圖每小時 15 美元、加拿大選制改革。每組僅取來源順序前六則 approved 原文，不代表全體，不生成缺少的分群、略過票或支持度。保留原文語言，介面中英雙語。
- [Dataset manifest](../public/data/polis-datasets.json) 附來源、CC BY 4.0 attribution、雜湊與省略欄位；原始 author-id／個別投票沒有重新發布。

The adapter preserves aggregates, group redactions, representative statements, bridging scores, matrix coverage and clustered share. It excludes personal coordinates. Seed/unknown-origin text is not participant speech. Synthesis retains source-linked passages, not every narrative subfield; retain the original. `mathRevision` is not a timestamp, and matching counts do not prove matching revisions. Three six-row historical excerpts are pinned and attributed; missing method data is not reconstructed.

## P3：指定 Decidim adapter

以 [Metadecidim API 文件](https://meta.decidim.org/api/docs/object/proposal/) 和實際唯讀回應為準。保存多語 title/body/answer、原始 state、回覆時間、版本數及 title/body/state/answer/date changeset。HTML 以文字呈現，不執行。作者與無關變更不攜出。

伺服器 `decidim.version` 回傳 null；只釘選觀測日期、檔案 hash 與指定格式，不猜版本。前三筆回應 `hasNextPage:true`，不是完整活動。原版採納標籤不自動轉為本地承諾。

```sh
node scripts/export-decidim-readonly.mjs /private/tmp/metadecidim-proposals.json
# In Handoff or Workspace, choose Metadecidim and preview this file.
```

This named-instance adapter was checked against three real proposal responses. It preserves translations, states, timestamps and filtered version changes. The server version was undisclosed; the page is partial. No remote mutation or shared acceptance occurred. Public fixtures replace source content with fictional text.

V2V／Assemblis 僅有論文表 1 的候選欄位對照：[待驗收項目](../public/data/partner-acceptance.json)。需要真實格式的可分享測試檔後才能完成 adapter；不以自己創造的格式宣稱相容。

V2V/Assemblis mappings remain candidates from paper Table 1, pending actual shareable exports. Functional local implementations below do not establish compatibility with those services.

## P4–P6：本機主持功能

| 能力 / Capability | 已實作 / Implemented | 限制 / Limit |
|---|---|---|
| 更正 / Corrections | 申請、負責者、期限、接受／未採納理由、修訂與下游影響 / Requests, owner, due date, resolution reasons, revisions and downstream impact | 登記者的紀錄，不是身分驗證或法律效力 / Recorder attribution, not identity verification or legal authority |
| 場次 / Sessions | 議程時間、小組、線上／實體／混合、邀請／出席／發言／表態、障礙、會後三項回饋 / Agenda, groups, setting, participation observations, barriers and three feedback dimensions | 主持人登記；不是視訊服務，不代填參與者評分 / Facilitator records, not conferencing; no invented ratings |
| 提案 / Proposals | 固定門檻、草案→討論→可推進→試行→回顧、佐證、少數意見 / Fixed thresholds, stages, evidence and minority views | 尚非 Evocracy 代表選拔或 Swarmcheck 完整演算法；沒有建立跨工具投票身分對應 / Not full upstream algorithms; no cross-tool voter identity matching |

更正接受會新增 `supersedes` 修訂，原文保留，受影響的已檢查成果會重新開啟覆核；待處理更正納入下一輪追蹤。提案未覆核、門檻不足、有未解更正或使用舊修訂時，不能逕自推進。這些限制不代表門檻本身足以證明共識。

`operations` 是 workspace v1 的可選延伸，另有 [schema](../public/schemas/delib-operations/v1.json) 與關係／狀態驗證。舊備份沒有此欄位仍有效。各次操作留歷程，完整備份一起保存。不同分頁更新採比較後保存，工作台的舊快照不能覆寫新版 operations；遇到衝突需重新載入。

Corrections create immutable revisions and reopen reviewed descendants. Open requests carry into follow-up. Proposal advancement requires evidence, local review, declared thresholds and resolved correction holds. Operations are optional, versioned workspace data with structural and transition checks. Old backups remain valid. Compare-and-save prevents the studio from overwriting a changed issue, while workspace saves protect newer operations.

## P7：Hypha 的具體發現與未完成工作

論文的 Hypha 對應 [Hypha Worker Co-op Governance Experiment](https://github.com/hyphacoop/governance-experiment/tree/a9cbcf1efe8a589e24af565b53efba95d1444256)，不要混為同名申請管理或 DAO 產品。

已依 `dashboard/src/stores.js` 的 `exportData` 寫出獨立 adapter，沒有複製上游實作。上游 repo 為 GPL-3.0。其 exported_data.json 含 proposals、githubIssues、barChart、lineGraph、decisionLog。

**重要限制**：`single-choice`、Yes/No/Abstain 是匯出預設值；`result` 可能只是 A/B 標籤。GitHub 狀態、日期及 comments_count 也有 placeholder。Delib 不把它們當成已確認表決、零留言或真實日期。匯出 ID 依陣列位置產生，所以以檔案雜湊分開來源，不自行串成跨版本同一紀錄。私人帳號／試算表／群組沒有被存取。

Hypha's pinned export contract is supported with synthetic tests. Default ballot labels and placeholder issue metadata are not verified facts. Index-based IDs are isolated by file hash; no false cross-version joins are created. No private account was accessed and no upstream acceptance is claimed.

[Make.org 官方產品說明](https://about.make.org/en/start-a-project)不能代替匯出契約；尚未取得可用測試檔和資料範圍，因此沒有猜測格式 adapter。外部合作清單與欄位候選已建立但**未發送**。這是 P3／P7 尚未完成的部分。

Make.org still requires an actual permitted export contract and fixture. The partner acceptance checklist is prepared but unsent. These are outstanding P3/P7 requirements.
