# 人物角色卡與個人化旅程

這輪讓「人物旅程」成為可以翻面的插畫角色卡，並把人物的期待、參與限制與模擬資料中的成果分開呈現。

- 14 張獨立生成的插畫，統一台灣街景與編輯插畫風格。卡面有角色、序號與動機；卡背有動機、限制、誘因與期待成果。
- 14 位人物各自有 8 個步驟行動提示，以及 3 輪不同的參與焦點。選輪次或步驟會更新個人化提示、出席方式及來源紀錄。
- 三輪 × 八步驟的 336 個出席／資料關聯位置仍由既有固定案例計算。新文案沒有更動 `flow-demo.json`，也不把缺席者寫成在場。
- 每位人物可直接追查第一則原話或最近衍生成果，並下載包含編寫提示、出席與來源 ID 的 v2 JSON 旅程。
- 角色卡可用鍵盤翻面，螢幕閱讀器只讀取目前卡面；減少動態效果模式取消翻轉動畫。手機以橫滑瀏覽八步驟，選取步驟會保持在地圖可見範圍。
- 下拉箭頭統一保留 14px 邊距、42px 文字避讓空間；IN/OUT 圖示不再超出窄連接欄，工作台步驟間箭頭置中。

## 插畫與內容

使用內建 `image_gen`，逐一生成 14 張圖；工具未回報實際模型識別碼，因此不把本次執行宣稱為特定模型版本。沒有使用 CLI 或另接 API。

完整提示詞與圖片對照：[persona-art-prompts.json](persona-art-prompts.json)。上線資產位於 [public/images/personas](../public/images/personas)，每張為 640 × 960 JPEG，14 張合計 4,114,962 bytes。網頁版本僅縮尺寸及編碼，沒有改動插畫內容；原始 PNG 保留在生成工具的預設目錄。收合的卡組採延遲載入，避免首次載入所有卡面。

個人設定：[persona-profiles.json](../public/data/persona-profiles.json)。期待成果與正向感受屬編寫情境；「資料足跡」才是固定案例中的原話或衍生成果。被引用不代表出席、同意或實際政策落實。
