# Delib 0.6 · 從流程導覽到議題工作台

## 使用者可以做什麼

- 首頁以「我要辦一場／我要參與／先體驗看看」分流。參與入口使用主辦者提供的連結，不列出私人活動。保留全部 38 項盤點。
- `/workspace` 為中英文的本機議題工作台。建立議題、保留輪次、檢查／修訂紀錄、搜尋原話、追蹤後續、比較跨輪變化、接下一輪，以及私人 JSON 備份與匯入。
- Form → TTTC → Reply 的單一路徑有實際建立與讀回介面。所有建立都先呈現傳送內容與目的地，再由使用者確認。TTTC／Reply 有界限的進度讀取：每 8 秒，最多 15 次；離開分頁停止，可手動繼續。建立失敗不自動重送。
- 3 個教學情境各有 2 個選擇，會改變既有模擬的輪次與步驟，解釋不同安排的代價；不製造新票數或宣稱虛構分支已實際執行。
- 原創 stroke SVG 圖示搭配文字，用於資料類型、工具、入口、流程與操作。3D 接近可視區才載入，畫質可依慢幀降低；手機預設目前資料卡，可展開完整來源圖。提供前／後一步、播放速度與還原分頁視圖。

- `/voice` 讓公民在分頁內開啟主辦者提供的私人聲音回條，不要求取得整份私人議題、不上傳或保存檔案；回條是快照，不會自動同步。

## 資料的意義與限制

`delib-workspace/v1` 是新的本機操作契約，與 `delib-rounds/v1` 並存，沒有宣稱所有上游工具已原生支援。

- 來源文字與來源 ID 保留。Form 重新讀取相同資料不重複新增；原文改變時追加修訂，舊文仍保留。從 Form 消失的來源不再列入本輪交接輸入，但本機歷史並未自動刪除。
- 送給 TTTC／Reply 的 CSV 使用工作台紀錄 ID，`interview` 留空，不把代碼或人數送進另一工具。Reply 的參考脈絡僅取人工檢查過的主題／方案，與直接回應原話的關係分開。AI 回覆草稿不會在下一輪被當作參與者原話送出。
- TTTC 引用 `commentId` 與 Reply 的 `sourceId` 必須與此次送出的 ID 相符；未知來源會拒絕整批接入。此檢查只能證明資料指向一致，不能認證模型歸納正確。
- `derivedFrom` 保存來源圖；`relations` 區分 derived、responds、revises、context，並預留 supports／opposes。UI 不自動推論支持或反對。`supersedes` 表達明確修訂；原文與修訂者紀錄保留。
- 主持人檢查與原發言者確認是不同欄位；稱呼與時間是本機紀錄，不是身分驗證或組織簽署。「已檢查」不表示共識、正式承諾，亦不改變上游報告公開狀態。
- 新輪次承接待檢查紀錄與未解問題，包含回到哪一步、理由、負責者、日期。未建置通知寄送或跨服務撤回／刪除同步。
- 真人的跨工具身分不自動串連，因此跨輪比較不推斷加入、離開或立場變化。模擬資料可對照固定角色，但區分「此輪有原話紀錄」與出席。

## 保存與服務邊界

議題存於 IndexedDB；並非帳號或雲端同步。瀏覽器清除資料會遺失本機進度，需私人備份。管理連結只保留在頁面記憶體，重新開啟 Form 需要再次貼上管理連結。備份與匯入排除管理憑證欄位。檔案包含私人來源文字，不適合直接公開。

新增 `POST /api/workspace/read`，限定 form／tttc／reply 與 10 位活動 ID，目的地取自已配置服務；不接受使用者指定 URL、不跟隨轉址。Form 的 `X-Form-Admin` 僅轉送到 Form 匯出端點，憑證不寫 log 或回傳。請求上限 2 KiB、結果上限 5 MiB、請求有逾時，錯誤不回傳上游私人內容。

方法導引延續第二輪來源；這一輪沒有新組織背書。技術參考：[IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API)、[Workers Request](https://developers.cloudflare.com/workers/runtime-apis/request/)。

## 驗證

- `npm run check`：121 個前端／資料／讀回測試、56 個 Worker 測試，型別與部署 dry-run 通過。
- `scripts/qa-workspace.mjs`：獨立 Chrome、桌面與 390px 行動視窗，攔截外部 API 以固定合約資料走完 Form → TTTC → Reply、來源追蹤、人工檢查、重新載入、本機備份、下一輪；檢查雙語首頁／故事、完整索引與無整頁水平溢出。
- `scripts/run-workspace-pilot.mjs --live-synthetic` 另提供明確啟用的正式服務驗證。只用虛構資料；結束刪除本次建立的活動並讀回 404／410，管理憑證不輸出。
- 手機驗證為瀏覽器尺寸模擬；尚非實機效能量測或真實參與者可用性研究。

正式服務的虛構活動建立／刪除驗證曾被自動核准審查擋下，尚未執行，等待使用者明確授權。攔截式瀏覽器測試不是正式服務間交換的驗證。
